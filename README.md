The sign taped to the door of a haunted server room:

> WARNING: the ghost in rack 4 reboots anyone who knocks — IT tickets take longer, and it never closes them.

Reads like a real taped-up warning sign (WARNING lead), collides IT life with the supernatural, and the punch is the ghost as a worse helpdesk than IT: it never closes a ticket. Specific haunting (rack 4), fresh, no generic ghost pun.

Pure Python stdlib, no network, no secrets. `main.py` writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and
verifies it byte-for-byte against a self-check gate (1–120 characters,
single line, exactly one sentence).

Built for the [Funniest Sign on a Haunted Server Room Door](https://make.fun/competitions/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a)
competition on [make.fun](https://make.fun).
